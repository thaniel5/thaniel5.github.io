# thaniel5.github.io

Personal website for **Ethan Campbell** — a spooky Halloween-themed portfolio site.

Live at: [thaniel5.github.io](https://thaniel5.github.io)

## Features

- Animated canvas bats that fly across the screen with flapping bezier-curve wings
- Flickering hero title with CSS light-flicker animation
- Haunted city skyline silhouette with glowing windows
- Pulsing moon, floating ghosts, dangling spider, and SVG cobwebs
- Scroll-reveal fade-in on cards and sections
- Sections: About, Skills, Projects (Grimoire), Contact

## Stack

Pure HTML/CSS/JS — no framework, no build step. One file: `index.html`.

Fonts via Google Fonts: [Creepster](https://fonts.google.com/specimen/Creepster), [Cinzel Decorative](https://fonts.google.com/specimen/Cinzel+Decorative), [Special Elite](https://fonts.google.com/specimen/Special+Elite).

## Development
